## 一、项目总览

### 1.1 产品定位

面向个人投资者（本人及家人）的 AI 驱动投资分析工具，集资讯聚合、持仓管理、智能推荐、实时追踪、盘后复盘于一体，帮助用户在 **A 股、港股** 两大市场做出更理性的投资决策（✅ 已确认：用户实际交易 A 股 + 港股；美股模块保留但默认关闭，供家人或未来使用）。

### 1.2 核心设计原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | 零成本运行 | 除 DeepSeek API 调用费用外，数据源、工具链、部署环境均免费 |
| 2 | 本地优先 | 所有计算与数据存储在本机完成，保护隐私，无服务器月费 |
| 3 | 全天候在线 | 电脑保持开机运行，任务调度带容错补跑（⚠️ 开机时长不确定，按 7×24 设计 + 补跑机制） |
| 4 | AI 原生 | 分析、推荐、总结均由 DeepSeek 大模型驱动，非规则引擎 |
| 5 | ✅ GitHub 托管 | 项目部署到 GitHub 公开仓库（MIT 许可证），持续进行版本化更新 |
| 6 | ✅ UI 简洁直观 | 界面以简洁直观为主，淡蓝色为主色调，仅浅色主题（不做暗色模式） |
| 7 | ✅ 家人可用 | 软件可能给家人使用：首次使用向导式引导（API Key 配置、理财数据导入均有引导说明），非技术用户也能完成配置 |
| 8 | 免责声明 | AI 推荐与建议仅供参考，不构成投资建议；应用内与 README 均需注明 |

## 二、系统架构

### 2.1 整体架构图

（沿用用户原设计，五层架构）

- L5 用户交互层：资讯看板 / 持仓总览 / 推荐中心 / 追踪管理 / 盘后报告 / 智能问答 / 自选股看板 / 风险分析 / 投资复盘 / 宏观研判 / 系统设置
- L4 智能体编排层：资讯聚合 / 股票推荐 / 异动追踪 / 盘后总结 / 智能问答 / 风险分析 / 投资复盘 / 宏观研判 共 8 个 Agent
- L3 AI 模型与记忆层：DeepSeek API + 用户画像 / 虚拟账本 / 历史记忆
- L2 数据处理层：定时任务调度 / 数据清洗 / 多源融合 / 缓存 / 本地存储
- L1 数据源接入层：行情 API（AKShare + BaoStock + yfinance）/ 财经资讯（RSS + API）/ 个人理财软件（finance.db 只读）/ 宏观数据（AKShare + FRED）
- 通知服务：应用内通知（本期）→ 企业微信 Webhook（二期）
- 本地存储：SQLite 主库 + 缓存目录 + 日志目录

### 2.2 技术选型

| 层次 | 技术选型 | 说明 |
|------|----------|------|
| 桌面壳 | **Electron（✅ 已确认）** | 与个人理财软件技术栈完全一致（Electron 40 + electron-builder + electron-updater），本机零额外安装；打包、自动更新、GitHub Actions 发布流程直接复用理财软件已跑通的实践 |
| 前端界面 | React + TypeScript + TailwindCSS | 生态成熟，与理财软件一致（React 19 + TS） |
| 前端图表 | ECharts | 与理财软件一致（ECharts 6），K 线另评估 Lightweight Charts |
| 后端服务 | Python (FastAPI) | AI 生态最成熟；用 PyInstaller 打包为可执行文件随应用分发 |
| 定时调度 | APScheduler | cron 表达式 |
| AI 模型 | DeepSeek API（deepseek-chat / deepseek-reasoner） | 应用内引导式配置 Key（✅ 面向家人） |
| 本地数据库 | SQLite | 零配置、零费用 |
| 通知 | 应用内通知中心（本期）→ 企业微信 Webhook（二期） | ✅ 已确认先应用内 |
| A 股数据 | AKShare（主）+ BaoStock（备） | 免费 |
| 港股数据 | AKShare（主）+ yfinance（备） | 免费 |
| 美股数据 | yfinance（主）+ AKShare（备） | 保留模块，默认关闭 |
| 资讯数据 | RSS + AKShare 新闻 + 东方财富公开接口 | 合规免费 |
| 宏观数据 | AKShare 宏观模块 + FRED API | 免费 |

### 2.3 关键架构决策（新增/修正）

1. **行情轮询频率修正** ⚠️：原方案 A 股 10 秒 / 港股 10 秒 / 美股 15 秒轮询，与免费数据源实际延迟（A 股约 15 秒、港股/美股约 15 分钟）不匹配——港股 10 秒轮询拿到的仍是 15 分钟前的数据，纯属浪费。修正为：
   - A 股：10~30 秒轮询（15 秒延迟可接受）
   - 港股：1~5 分钟轮询（数据源 15 分钟延迟，5 分钟拉取足够及时发现异动）
   - 美股：1~5 分钟轮询（同上，默认关闭）
2. **多币种折算**：统一按当日汇率折算为人民币（CNY）展示总资产（借鉴理财软件汇率表 exchange_rates 方案）；美股资产按美元原币展示、汇总折算。
3. **交易日历**：A 股 / 港股 / 美股各自节假日判断（AKShare 提供交易日历接口），周末与节假日不推送、不轮询。
4. **Windows 睡眠处理**：应用启动时检测电源计划并提示建议"从不睡眠"；提供开机自启选项；错过任务自动补跑（如开机后补生成当日盘前/盘后简报）。
5. **后端分发**：FastAPI 后端用 PyInstaller 打包为单文件 exe，由 Electron 主进程以 child_process 子进程方式拉起（含崩溃自动重启），随安装包分发，用户无需装 Python。
6. **API Key 安全**：DeepSeek Key 本地加密存储（借鉴理财软件 AES-256-GCM + secret.key 方案），绝不允许入库或上传 GitHub。

## 三、功能模块详细设计

### 模块一：每日盘前资讯聚合推送 ✅

- 每个交易日 08:00 自动抓取 A 股、港股（+美股隔夜）最新资讯，AI 分级（重大/中等/一般）、生成一句话摘要、关联持仓高亮、跨市场联动标注；09:00 推送到应用内通知中心。
- 数据源：AKShare 新闻接口（主）+ 东方财富 RSS（备）；港股 AKShare 港股新闻 + yfinance；美股 yfinance 新闻（默认仅作隔夜参考）。
- 周末/节假日不推送（自动识别三市场交易日历）。
- 推送内容模板沿用原设计（重大事件 / 持仓相关 / 美股隔夜 / 宏观日历 四段式）。

### 模块二：个人理财软件数据整合（只读）✅（对接方案已实地调研）

**对接对象**：用户自研「个人理财投资软件」（Electron 应用）。
- 源码目录：D:\家\home\个人理财投资软件
- 安装后数据目录：C:\Users\<用户>\AppData\Roaming\personal-finance\finance.db（SQLite，已实地读取，27 张表）

**可读取数据（已核实表结构）**：

| 需求数据 | 对应表 | 说明 |
|----------|--------|------|
| 持仓明细（代码/名称/数量/成本/现价/盈亏） | assets | 10 条现有数据，含 code/name/quantity/cost_price/current_price/market_value/profit_loss 等字段 |
| 资产总览（总资产/现金/投资） | investment_accounts + accounts + account_balances + net_worth_history | 投资账户 3 个、银行账户 8 个、净值历史 14 条 |
| 历史交易记录 | transactions | 买卖时间/价格/数量/费用，17 条 |
| 汇率（多币种折算） | currencies + exchange_rates | 6 币种、525 条汇率历史 |
| 价格历史 | asset_prices | 473 条 |

**同步机制**：
1. 首次使用向导：询问是否使用「个人理财投资软件」→ 检测 finance.db 是否存在
2. 存在：自动只读导入（✅ 用户确认：自动对接为主）；每小时定时同步 + 手动即时同步
3. 不存在：引导手动录入或 CSV 导入；用户也可选择不导入，仅获得 AI 配置建议（✅ 用户确认）
4. 只读原则：绝不写入理财软件数据库（打开方式用 SQLite 只读模式）

**风险点** ⚠️：
- finance.db 目录存在 secret.key（理财软件加密密钥），部分敏感字段可能加密存储；P1 阶段需验证 assets/transactions 等表是否明文可读。若加密，方案为在理财软件侧增加「导出持仓快照 JSON」功能（自研软件，可行性高，且理财软件已有 data:exportAll 备份能力可参考）
- 两个软件同时运行时 finance.db 可能被占用：SQLite 只读 + WAL 模式可并发读，需 P1 实测

### 模块三：AI 股票推荐 ✅

- 用户画像：首次使用引导问卷（风险偏好/资金量/市场/持仓周期/经验），可随时在设置修改（✅ 已确认，新增"是否使用理财软件"一步）。
- 短线推荐：技术面（放量突破、MACD、KDJ、布林带）+ 资金面（主力净流入、龙虎榜、北向/南向资金）+ 消息面；输出入场区间/止损/目标价/置信度。
- 长线推荐：基本面（PE/PB/ROE、营收净利增速、现金流）+ 行业面 + 技术面（周/月线趋势）；输出估值区间/长线逻辑/风险等级/置信度。
- 约束规则：持仓冲突检测、资金匹配（单手价 ≤ 可投资金额 10%）、风险匹配、市场匹配（仅 A 股 + 港股）。
- 推荐记录与回测：每条推荐保存时间/价格/类型/置信度，自动统计胜率与平均收益，设置页查看准确率报告。
- **虚拟账本定义**（✅ 由我方定义，用户认可）：「虚拟账本」= AI 推荐记录回测（必须）+ 可选模拟交易功能（虚拟资金买卖练习，P4 阶段实现）。

### 模块四：AI 股票实时追踪与异动通知 ✅

- 追踪列表最多 10 只，逐股配置异动条件（价格急涨急跌 ±1%~10%、成交量 1.5~10 倍、大单 50~500 万、技术信号开关、突破均线、AI 综合判断开关），支持暂停/删除。
- 通知分级：紧急（5 分钟跌超 5%、触及止损）/ 关注（放量、技术信号、AI 判断）/ 提示（接近关键价位、盘后公告）。
- 本期通知到应用内通知中心（弹窗 + 列表）；企业微信模板（原设计）二期启用。
- 轮询：A 股 10~30 秒；港股 1~5 分钟（修正，见 2.3）；非交易时段不轮询。
- 频率控制：同一股票同一类型异动 15 分钟内不重复。

### 模块五：盘后智能总结与次日预判 ✅

- A 股 15:30、港股 16:30 各生成市场总结；17:30 合并生成全市场日报（无美股时）。
- 报告结构：当日市场全景（指数/板块涨跌/资金流向/情绪指标）+ 持仓与追踪回顾 + 次日机会预判（异动方向/潜在机会/风险预警）+ 次日操作建议清单。
- 美股盘后总结（05:00）保留功能，默认关闭。
- 推送方式：应用内（本期）。

### 模块六：智能问答与研报解读 ✅

- 自然语言问答：个股分析/对比分析/持仓诊断/行业分析/策略咨询/数据查询，结合实时数据和用户持仓。
- 研报解读：东方财富研报摘要 + AKShare 研报接口，AI 提取目标价/评级变化/关键假设/风险提示，300 字摘要 + 持仓关联分析。
- ⚠️ 研报数据源（东方财富免费研报）可用性需在 P1 验证，若接口不可用则降级为仅新闻聚合。

### 模块七：投资组合风险分析 ✅

- 指标：单只持仓集中度（>20% 预警）、行业集中度（>40% 预警）、最大回撤、Beta（>1.5 提示）、夏普比率（<0 提示）、VaR（95% 置信度日损失）。
- 压力测试：模拟大盘跌 10% / 板块跌 20% / 汇率贬值 5% 等场景，AI 基于 Beta 与行业暴露估算。
- 预警通过应用内通知。

### 模块八：AI 投资复盘与学习 ✅

- 每周日 10:00 周度复盘、每月 1 日 10:00 月度复盘（+ 推荐准确率报告）、每季度复盘。
- 行为分析：追涨杀跌、过度交易、处置效应、确认偏差、锚定效应。

### 模块九：自选股看板 ✅

- 自定义分组、实时行情、日/周/月 K 线 + 技术指标叠加（MA/MACD/RSI/布林带）、基本面速览（PE/PB/ROE/市值/营收增速）、关联资讯、一键加入追踪 / 一键 AI 分析。

### 模块十：宏观形态分析 ✅

- 追踪：中国宏观（GDP/CPI/PPI/PMI/社融/M2/LPR）、美国宏观（非农/CPI/利率/10Y 国债）、全球市场（美元指数/原油/黄金/VIX）、市场情绪（融资融券/南北向资金/涨跌家数/成交额）。
- 宏观信号四色约束（🟢 正常 / 🟡 偏谨慎 / 🔴 暂停短线 / ⚫ 暂停买入），影响推荐模块行为。

### 模块十一：多市场交易设置 ✅

- 勾选交易市场（默认 A 股 + 港股；美股开关保留）。
- 联动：盘前资讯三市场都推送但用户市场置顶；行情轮询仅勾选市场；推荐仅勾选市场；追踪仅允许添加勾选市场股票。
- 各市场盘前/盘后推送时间独立配置。
