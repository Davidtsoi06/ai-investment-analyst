## M1 我的股票池（决策：复用自选股看板；不足 5 只不补蓝筹）

### 前端
1. 「自选股看板」导航改名「我的股票池」；页头说明：AI 推荐只从池内分析，可建多个表（组）放心仪股票
2. 推荐中心加「管理股票池」快捷入口（跳 /watchlist）
3. 推荐中心生成范围选择（生成弹窗扩展）：全市场自动选择 / 我的股票池（可多选组：A股表、港股表…全部/勾选）/ 保留 v1.0.9 意图输入（可叠加）
   - 池范围且股票池 <5 只 → 提示「股票池仅 N 只太小，请先添加观察股」，不做蓝筹自动补足（可手动切回全市场）
4. 「分析我的股票池」按钮 → 池内体检：每只一行 现价/涨跌/位置标签（高位·中位·低位，图例说明口径）/RSI/均线状态/一句话结论（值得关注·观望·回避+理由）；有 Key 时 AI 逐只点评+Top3
   - 位置口径（规则+图例）：近 60 日区间分位 >0.75=高位、<0.25=低位、其余中位；结合 RSI(>70 高位警示) 与 MA 乖离修正

### 后端
1. POST /api/pool/analyze：{groups?:[组名]} → 读 watchlist 分组 → 并行行情+K线60 → 规则位置判定 → items + 可选 ai_summary
2. AI 点评分批（每批 ≤8 只）
3. 候选池 scope：'market'=全市场现有逻辑 / 'pool'=选中组内（不补足）

## M2 短线/长线分开 + 数量 5+ 与资料（决策：方案 C）

### 前端
1. 按钮拆分：「🔴 生成短线推荐」「🔵 生成长线推荐」；范围弹层加类型选择
2. 展示：推荐级（confidence≥阈值）+ 观察清单（补足总数 ≥5，标「观察级·低置信度」）
3. 短线卡内嵌 60 日 K 线迷你图 + 标注 入场/止损/目标 水平线 + 现价虚线；理由三行（技术/资金/消息）
4. 长线卡展开：估值（PE/PB/市值）、周/月趋势、相关研报标题观点（复用 /api/research/list）、相关资讯 2-3 条

### 后端
1. POST /api/recommend/run body：{intent, scope:{type:'market'|'pool', groups?:[]}, mode:'short'|'long'|'both'}；mode 只跑对应线程并独立当日缓存
2. AI 提示词：输出 5~8 只，不足按信心补足到 5（可含观察级）；sanitize confidence≥40 保留
3. 补足：AI 输出+规则达标=推荐级；<5 时规则 40~59 分补观察清单；仍不足返回原因但推荐级照常展示

## N1 Token 用量 + 余额 + ≤¥5 弹窗（决策：D1=B、阈值 ¥5 CNY）
