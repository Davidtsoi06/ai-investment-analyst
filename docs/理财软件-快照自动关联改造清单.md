## 一、背景与目标

现状：用户需在理财软件「设置 → AI 助手配置 → 持仓数据导出」手动点"选择文件夹"指向
AI 投资分析软件数据目录（%APPDATA%\ai-investment-analyst\data\portfolio）。该路径含 Windows
用户名，换电脑/换用户后目录不同，每次都要重新手动选择，易错且繁琐。

目标：**理财软件免配置自动关联**——本机检测到 AI 投资分析软件数据目录即自动把持仓快照
写入其中；换电脑/换用户后因路径基于 %APPDATA% 环境变量自动跟随，装好两个软件即自动连通。
保持**快照文件交换**模式（portfolio_snapshot.json），绝不直读/直写对方数据库，维持安全软件
友好（v1.0.5 起两软件已为此切换到纯文件交换，此原则不可回退）。

## 二、行为规格（执行 AI 请严格按此实现）

### 2.1 探测目录
- AI 软件数据目录判据：`path.join(app.getPath('appData'), 'ai-investment-analyst', 'data')` 存在
  （Electron `app.getPath('appData')` = %APPDATA%，自动适配用户名；勿用写死用户名路径）
- 自动导出目标：`path.join(app.getPath('appData'), 'ai-investment-analyst', 'data', 'portfolio')`
- 更强判据（可选）：同时要求该 data 目录下存在 `ai_invest.db` 或 `secret.key` 才视为"已安装"，避免误判

### 2.2 关联模式（三态，优先级从高到低）
| 模式 | 条件 | 行为 |
|---|---|---|
| manual | 已保存的导出文件夹 **存在** | 完全尊重用户手动选择，任何情况不覆盖 |
| auto | 未保存文件夹，**或**已保存但文件夹**已不存在**（换电脑/目录被删） | 探测到 AI 数据目录 → 自动 setPortfolioFolder(自动路径) + 立即导出一次快照 |
| none | 未保存文件夹且未探测到 AI 数据目录 | 不设置、不导出；UI 提示"未检测到，安装后重启自动关联" |

- auto 模式只在"未手动配置或手动配置已失效"时介入 → 用户手动换目录后不再被自动覆盖（manual 优先）
- 清除按钮语义：清除 = 回到 auto 探测逻辑（并非禁用自动），UI 文案需说明

### 2.3 触发时机
1. **应用启动后**（主进程 `whenReady` 流程末尾的后台任务 setTimeout 区，与"余额重算/记录净资产"同区块，不阻塞首屏）：调用自动关联函数（try/catch 非致命，失败 console 日志）
2. 启动后每次导出照旧：持仓交易/编辑（asset-ipc exportPortfolioSnapshot(true)）与价格批量刷新（scheduler schedulePortfolioExport 30s 节流）——自动关联设置后这些**无需改动**即生效

### 2.4 错误处理
- 自动关联时的导出失败沿用现有 lastError 通道（aiPortfolio.lastError → 设置页展示），不新增静默路径
- 自动关联动作打 console.log（如 '[aiPortfolio] 自动关联: %s (mode=%s)'），便于用户反馈排查

## 四、手动验收场景（发布前逐条过）

1. 【现状用户】两软件均已安装：升级理财软件 → 启动 → 设置页显示"✅ 已自动关联"+ 路径
   → AI 投资分析软件「持仓总览 → 同步持仓」成功、无任何手动配置
2. 【换电脑模拟】把 aiPortfolio.folder 设置清掉（或改一个不存在路径）重启 → 自动重新关联
3. 【手动优先】点「选择文件夹」指定别处 → 重启软件 → 路径不被自动覆盖（仍为手动目录）
4. 【未安装 AI 软件】理财软件在无 AI 软件机器启动 → 显示"未检测到"提示、无报错
5. 【导出回归】编辑一条持仓 → data\portfolio\portfolio_snapshot.json 自动更新（内容与 1.10.17 一致）
6. 【密码锁用户】启用锁屏时启动：自动关联在后台完成，锁屏界面无感知、解锁后设置页状态正确
