## 一、推荐依据（5 项）

| 依据 | 标识 | 引擎 |
|---|---|---|
| 📰 消息面 | news | 资讯→主题聚类→AI 推断受益标的（含未点名产业链个股）→技术校验防追高 |
| 📈 技术面 | technical | 现有规则（突破/均线/MACD/KDJ/RSI）+ AI |
| 💰 基本面 | fundamental | 现有长线规则（PE/PB/趋势）+ AI |
| 💵 资金面 | capital | 量比、放量突破、成交额异动、换手率 |
| 🏛️ 政策面 | policy | 政策资讯识别→AI 解读受益行业/产业链→技术校验；支持用户输入关注领域 |

默认勾选：📰消息面 + 📈技术面；全不勾选 → 阻止生成并提示。

## 二、各依据数量配额（用户可自定义）

设置页「推荐偏好」中，每个已勾选依据可设置数量：

```
推荐依据（勾选启用；数字为该依据最多产出的推荐条数）
[✓] 📰 消息面   [ 3 ] 条
[✓] 📈 技术面   [ 5 ] 条
[ ] 💰 基本面   [ 3 ] 条
[ ] 💵 资金面   [ 2 ] 条
[ ] 🏛️ 政策面   [ 2 ] 条
（默认值如上；0 或留空 = 该依据不产出）
```

**数量交互规则（v3 定稿，用户确认）**：
1. **设置页**保存各依据的默认配额（上图，用户可改）
2. **每次生成时弹窗询问**：弹窗中列出已勾选依据及其数量输入框（预填设置值），用户可当场修改；
   弹窗显示「本次预计 X 只」与提示「当前画像档位建议上限 Y 只（保守5/稳健8/激进10）」
3. **用户本次设定优先**：若本次总量超过档位建议上限，仅提示确认（"超过当前画像建议上限，仍要生成？"），确认后按用户设定执行
4. 各依据先按各自配额产出 → 合并去重 → 归属不清/不足时按现有补足机制（带「⚠补足·未达评估线」标注）
5. 生成的完成消息展示明细："短线 6 只（消息面 2 · 技术面 3 · 资金面 1）"

## 三、信源标注与预览（用户新增要求）

### 3.1 数据
- 推荐条目新增 `sources` 字段（JSON 数组，落库）：`[{title, url, source, date}]`
- 消息面/政策面：附**诱因资讯 1~3 条**（真实 URL，来自本地资讯库/抓取源）
- 技术面/基本面/资金面：附**该股相关资讯 1 条**（本地资讯库名称/代码命中，作为佐证），无则留空
- 有效期：只取最近 30 天资讯；单条推荐最多 3 条信源

### 3.2 展示与交互
| 交互 | 行为 |
|---|---|
| 推荐卡「📰 信源」行 | 显示信源标题（含来源与日期），如 `📰 钻石散热新技术突破（东方财富 · 09-05）` |
| 点击标题 | 打开原文网站（现有系统浏览器方式：`window.app.openExternal`） |
| 「预览」按钮 | 应用内弹窗预览：标题 + 一句话简述 + 来源 + 日期 + 「打开原文」按钮（用本地已存内容，离线可看） |
| 推荐历史 / 回测列表 | 同样显示信源条目与可点击链接 |
| 政策面条目 | 信源为政策文件/权威媒体报道，并标注催化时间窗 |

## 四、依据记忆策略（用户确认）

设置页新增「依据选择记忆」：
- **跟随设置（默认）**：每次生成使用设置页保存的依据与配额；弹窗改动仅本次生效
- **记住本次选择**：弹窗改动后，生成完成时询问「是否将本次依据与配额保存为默认？」→ 用户选择 保存 / 不保存

政策面关注领域输入框的内容，随"保存默认"一并保存（见待确认 4）。

## 五、政策面关注领域输入（用户确认）

- 生成弹窗中勾选 🏛️ 政策面时，出现输入框：`关注领域（可选，留空=全量政策扫描）`，示例占位符："新能源、半导体、低空经济"
- 输入内容用于：AI 政策解读时聚焦该领域（提示词注入过滤指令）+ 结果中信源/受益逻辑贴合该领域
- 是否记忆：随"记住本次选择 → 保存"一并持久化

## 六、组合、去重与排序

1. 各依据链**并行执行**、一次性出结果（用户确认不分批）
2. 按 (symbol, rec_type) 合并；多依据命中 → 一条，徽章并列，理由按 消息面/政策面 → 技术面 → 基本面 → 资金面 拼接；信源合并去重（最多 3 条）
3. 排序：多依据命中优先 > 置信度降序 > 消息面/政策面「早期」条目优先
4. 数量：依据配额 → 档位上限截断 → 不足按下限补足（带标注）
5. 风控约束照旧（持仓冲突 / 单手价超资金线 / 风险超承受 → 拦截并说明）

## 八、分期

- **一期（v1.2.0）**：5 依据多选 + 配额自定义 + 消息面/政策面引擎 + driver/sources 落库 + 依据徽章 + 信源展示与预览 + 记忆策略 + 政策领域输入
- **二期**：回测按依据分组胜率、「主题雷达」面板（自定义主题、时间线、首次出现时间）、热点/板块依据
- **三期**：追加早期信息源（行业媒体/公告/互动平台）+ 主题历史回溯

## 九、风险与限制

1. 消息面/政策面依赖 AI 行业知识，可能"蹭概念" → 置信度 + 阶段标注（早期/发酵/高潮）+ "请自行核实"
2. 一期抓不到 3 月那种产业早期消息（源覆盖限制，三期改善）
3. 生成耗时增加（消息面+政策面各一轮 AI 调用，一次性出结果）
4. 无 AI Key：消息面/政策面降级为"仅识别被资讯点名的公司"，并注明
5. 信源依赖本地资讯库已有条目；若某标的无相关资讯则不显示信源行
