# 开发日志规范

| 项目 | 内容 |
|------|------|
| 文档版本 | V1 |
| 日期 | 2026-08-30 |

## 一、目的

记录每天完成事项与待办事项，保证开发过程可追溯、可续接（跨 AI 会话/跨天续接时，日志是唯一事实来源）。

## 二、存放位置与命名

- 目录：dev-logs/
- 文件：dev-logs/YYYY-MM-DD.md（如 2026-08-30.md）
- 每个自然日一个文件；当天多次会话写入同一文件。

## 三、格式模板

# 开发日志 YYYY-MM-DD（周X）

## 今日完成
- [任务描述]

## 待办事项（未完成，顺延）
- [任务描述]

## 决策记录
- [重要决策及理由]

## 问题与风险
- [问题/风险及应对]

## 明日计划
- [计划]

## 版本状态
- 当前版本：vX.Y.Z（未发布/已发布）

## 四、维护义务（AI 助手必须遵守）

1. 每次开发会话开始：先读取 dev-logs/ 最近一篇日志，确认当前进度与待办。
2. 每次开发会话结束：必须更新当日日志（新增完成事项、更新待办、记录决策与问题）。
3. 跨天续接：新的一天开工时创建当日日志，并在开头引用昨日进度。
4. 发布版本当天：在日志中记录版本号、发布结果。
