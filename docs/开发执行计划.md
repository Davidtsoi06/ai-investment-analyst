## 一、执行原则（最重要）

1. **小步推进，不一口气做太多**：每个步骤都有明确的验收标准，完成一步 → 更新开发日志 → git 提交 → 停下汇报，确认后再进入下一步。
2. **稳定优先**：每步都必须能运行、能验证，不允许代码堆积后一起调试。
3. **安全红线**：API Key 与 .env 永不入库；理财软件数据库只读；发布流程按版本发布规范执行。
4. **版本化交付**：每个阶段结束发布一个版本（v0.1.0 → v1.0.0），每次发布严格走版本发布规范（更新 README/CHANGELOG、打包新安装包、删除旧安装包、推送）。

## 三、详细步骤

### S0 项目初始化与 GitHub 建仓（0.5~1 天）→ v0.1.0
- 任务：git init；创建目录骨架（desktop/frontend/backend/data/docs/dev-logs）；创建 README.md（功能定位+界面截图占位+免责声明）、CHANGELOG.md、LICENSE（MIT）、.gitignore（排除 .env/node_modules/dist/data 等）；配置 git 身份（已有 Davidtsoi06）；创建 GitHub 公开仓库 ai-investment-analyst；首次推送；配置 GitHub Actions 骨架（CI + 自动发布）。
- 验收：仓库在 GitHub 可见；本地与远端一致；.gitignore 生效（.env 不进库）。

### S1 Electron 壳最小化（1 天）
- 任务：Electron 主进程 + 渲染进程骨架；窗口（淡蓝主题标题栏）；系统托盘（最小化到托盘、退出菜单）；版本号显示；electron-builder 配置（NSIS 安装包）本地打包跑通；electron-updater 骨架。
- 验收：npm run dev 可开窗；npm run build 可出安装包并可安装运行。

### S2 前端骨架（1~1.5 天）
- 任务：Vite + React + TypeScript + TailwindCSS；淡蓝色系设计 token（按需求文档十一章规范）；布局（左侧导航 220px + 内容区）；路由与 11 个页面占位页（仪表盘/资讯/持仓/推荐/追踪/自选股/报告/风险/复盘/问答/设置）；公共组件（卡片/表格/按钮/徽章/金额）。
- 验收：应用可打开，11 个页面可导航，主题色正确。

### S3 后端骨架（1 天）
- 任务：FastAPI 应用入口；配置管理（config，支持 .env）；SQLite 初始化（建库建表，按需求文档 14 张核心表）；健康检查接口 /api/health；日志系统（app/agent/notification 三类日志）。
- 验收：后端可启动，健康检查通过，数据库表创建成功。

### S4 前后端联通（1 天）
- 任务：PyInstaller 打包后端为单文件 exe；Electron 主进程启动/停止 Python 子进程（child_process，崩溃自动重启）；渲染进程 ↔ 主进程 IPC ↔ Python HTTP（localhost 随机端口 + 令牌校验）；版本配套校验。
- 验收：安装包内一键拉起后端；前端能请求后端接口；后端崩溃自动重启。

### S5 A股+港股行情接入（1.5~2 天）
- 任务：AKShare 客户端（A 股主/港股主）；备用源（BaoStock / yfinance）与自动故障切换；统一行情数据模型（代码/名称/价格/涨跌幅/成交量等）；历史 K 线获取与缓存（daily 缓存）；实时行情轮询框架（A 股 10~30 秒、港股 1~5 分钟，按交易日历）；交易日历判断。
- 验收：A 股、港股各一只股票可获取实时行情与日 K；主源故障时自动切备用源。

### S6 理财软件对接（1.5 天）
- 任务：finance.db 只读打开（SQLite URI 只读模式 + WAL 并发验证）；字段映射（assets→持仓、investment_accounts→账户、transactions→交易、net_worth_history→净值、exchange_rates→汇率）；数据同步服务（每小时 + 手动）；首次使用引导（检测是否存在 → 自动导入 / 手动录入 / CSV 导入 / 跳过仅建议）；验证字段是否加密（secret.key 影响面）。
- 验收：能正确只读读取真实 finance.db 并展示持仓总览；绝不写入。

### S7 用户画像与系统设置（1 天）
- 任务：首次使用引导问卷（风险偏好/资金/市场/周期/经验 + 是否用理财软件）；系统设置页（多市场配置、通知开关、免打扰时段、DeepSeek API Key 引导配置（加密存储 + 测试连接）、数据源配置）；设置持久化。
- 验收：完整走一遍引导流程，设置全部生效。

### S8 资讯模块（1.5 天）
- 任务：资讯抓取（AKShare 新闻 + RSS）；去重（标题相似度 >85% 判同源）；AI 分级与一句话摘要（DeepSeek）；持仓关联高亮；跨市场联动标注；应用内通知中心（分级着色/免打扰/频率控制）；盘前定时（08:00 抓取整合、09:00 推送，交易日历判断）。
- 验收：某交易日 09:00 前收到完整盘前资讯。

### S9 自选股看板（1.5 天）
- 任务：自选股列表（自定义分组）；实时行情展示；K 线图表（日/周/月 + MA/MACD/RSI/布林带，ECharts）；基本面速览（PE/PB/ROE/市值）；关联资讯聚合；一键加入追踪、一键 AI 分析（入口）。
- 验收：添加股票后行情/K线/基本面/资讯正常展示。

### S10 推荐模块（2 天）
- 任务：推荐数据采集（技术指标 + 资金面 + 基本面）；DeepSeek 推荐（短线 + 长线，prompt 按技术设计规范）；约束规则（持仓冲突/资金匹配/风险匹配/市场匹配）；推荐记录存储与回测统计（胜率/平均收益）；推荐中心页面。
- 验收：能生成当日推荐并显示置信度；回测报告可查看。

### S11 追踪模块（2 天）
- 任务：追踪列表管理（最多 10 只、条件配置、暂停/删除）；异动检测（价格急涨急跌/放量/大单/技术信号/突破均线/AI 综合判断）；通知分级（紧急/关注/提示）；频率控制（同股同类 15 分钟不重复）；轮询调度（仅交易时段）。
- 验收：模拟行情波动可触发对应级别通知。

### S12 盘后总结（1.5 天）
- 任务：A 股 15:30 / 港股 16:30 市场总结（指数/板块/资金/情绪）；持仓与追踪回顾；次日机会预判；操作建议清单；17:30 合并日报；报告存档（daily_summary）。
- 验收：交易日收盘后自动生成完整日报并推送。

### S13 智能问答与研报解读（1.5 天）
- 任务：问答接口（结合实时数据 + 持仓上下文）；问答页面（流式输出）；研报抓取与 AI 摘要（目标价/评级/假设/风险 + 持仓关联）。
- 验收：典型问题（持仓诊断/个股分析/对比分析）回答可用。

### S14 风险分析与宏观研判（1.5 天）
- 任务：组合风险指标计算（集中度/回撤/Beta/夏普/VaR）；压力测试场景模拟；预警通知；宏观数据采集（AKShare + FRED）；宏观信号四色约束影响推荐。
- 验收：真实持仓可算出各风险指标；宏观环境判定生效。

### S15 投资复盘与虚拟账本（1.5 天）
- 任务：周/月/季度复盘报告（操作盈亏/胜率/行为偏差分析）；推荐回测统计（虚拟账本核心）；可选模拟交易（虚拟资金买卖）；复盘推送。
- 验收：可生成周度复盘报告；模拟交易可记录并统计。

### S16 打磨与正式发布（1 天）→ v1.0.0
- 任务：UI 细节美化；异常处理与日志完善；全流程回归测试（引导→数据→推荐→追踪→日报）；安装包全量测试（新装/升级）；按版本发布规范发布 v1.0.0。
- 验收：干净环境安装后全功能可用；升级路径正确。

## 四、执行节奏与确认机制

1. 每个步骤开始前：读取 dev-logs/ 最近日志 → 确认当前步骤 → 只做该步骤。
2. 每个步骤完成后：更新当日开发日志（完成/待办/决策/问题）→ git 提交（约定式提交）→ 向用户汇报 → 等待确认后再进下一步。
3. 每个阶段完成后：按版本发布规范发布版本（README/CHANGELOG 更新 → 打包新安装包 → 删除旧安装包 → tag → push）。**推送前必须先向用户汇报变更清单并取得明确确认，严禁直接推送。**
4. 遇到阻塞：记录到日志并汇报，不硬闯。
