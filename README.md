# AI 投资分析软件

面向个人及家庭的 AI 驱动投资分析工具（A 股 + 港股），集资讯聚合、持仓管理、智能推荐、实时追踪、盘后复盘于一体，帮助用户在三大市场做出更理性的投资决策。

## 功能特性

| 模块 | 说明 | 状态 |
|------|------|------|
| 每日盘前资讯 | 多源资讯抓取 + AI 分级摘要 + 持仓高亮 + 跨市场联动 | 规划中 |
| 持仓总览 | 只读对接个人理财软件（finance.db），自动/手动同步 | 规划中 |
| AI 股票推荐 | 短线 + 长线推荐，含约束规则与回测统计 | 规划中 |
| 实时追踪 | 最多 10 只股票异动监控，分级通知 | 规划中 |
| 盘后总结 | 当日复盘 + 次日操作建议清单 | 规划中 |
| 智能问答 | 结合实时数据与持仓的自然语言问答 | 规划中 |
| 风险分析 | 集中度/回撤/Beta/夏普/VaR + 压力测试 | 规划中 |
| 投资复盘 | 周/月/季度复盘 + 行为偏差分析 | 规划中 |
| 自选股看板 | 分组管理、K 线技术指标、基本面速览 | 规划中 |
| 宏观研判 | 全球宏观指标 + 市场情绪，约束推荐行为 | 规划中 |

## 技术栈

- 桌面壳：Electron + electron-builder + electron-updater
- 前端：React + TypeScript + TailwindCSS + ECharts
- 后端：Python FastAPI + APScheduler
- 数据：SQLite（本地存储）、AKShare / BaoStock / yfinance（免费行情）
- AI：DeepSeek API
- 发布：GitHub Actions + GitHub Releases（公开仓库，MIT 许可证）

## 快速开始（开发模式）

桌面壳（desktop/）：

- 安装依赖：cd desktop && npm install
- 开发运行：cd desktop && npm run start（构建 TS 后启动 Electron）
- 打包安装包：cd desktop && npm run dist（输出到 desktop/release/）

> 说明：S1 已打通 Electron 壳与 NSIS 安装包链路；完整前端界面（React）自 S2 接入。

## 安全与误报说明

- 本软件需联网获取**公开免费行情/资讯数据**（腾讯/东财/新浪/yfinance）与调用 DeepSeek API，因此会被部分杀毒软件/浏览器 SmartScreen 误报为可疑程序（未做代码签名）。这是开源个人项目的常见现象，**请放心使用**：
  - 下载后如遇 SmartScreen 提示：点击"更多信息" → "仍要运行"
  - 或右键安装包 → 属性 → 勾选"解除锁定" → 确定
  - 本软件不开源数据收集行为，仅访问上述公开数据源与 DeepSeek 官方 API；所有数据存储在本机
- **持仓数据对接（防误报友好方案）**：个人理财投资软件 v1.10.14+ 可在设置中配置"AI 投资分析软件数据文件夹"，任何持仓变化会自动导出 portfolio_snapshot.json 到该文件夹；本软件优先读取该本地文件（纯本地文件交换，无需读取其他软件的数据库），未配置时回退直接只读 finance.db
