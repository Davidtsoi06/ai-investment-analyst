# AI 投资分析软件

面向个人及家庭的 AI 驱动投资分析工具（A 股 + 港股），集资讯聚合、持仓管理、智能推荐、实时追踪、盘后复盘于一体，帮助用户做出更理性的投资决策。AI 输出仅供参考，不构成投资建议。

## 功能特性

| 模块 | 说明 |
|------|------|
| 主页（仪表盘） | 持仓资产总览 + 沪深/港股指数速览 + 今日推荐 + 宏观信号 + 通知 |
| 资讯看板 | 三区块：📌 我的股票池相关（持仓+池内股票命中打标）/ 🌍 海外市场（美英日韩多源，中文标题+简述自动翻译，点击看原文）/ 🗞️ 全市场要闻；AI 分级摘要，交易日 08:00/10:15/13:45 + 海外每 30 分钟自动抓取，可手动刷新 |
| 持仓总览 | 双数据来源：① 读取「个人理财投资软件」导出的 portfolio_snapshot.json（自动同步）；② 手动录入/编辑/删除持仓 |
| 推荐中心 | AI + 规则引擎双引擎；短线/长线独立生成（各带观察级清单）；范围可选 全市场 / 我的股票池分组多选 / 输入行业意愿（行业词典 16 组）；推荐卡可展开 K 线、直通个股诊股；回测统计与历史 |
| 追踪管理 | 异动监控（涨跌幅/量比/大单/技术信号），分级应用内通知 |
| 我的股票池 | 多表管理（建空表/市场范围/改名/删除，表内股票按代码自动排序）；搜索式添加（代码/中文/拼音首字母如 bd→百度，候选实时现价）；股票池体检（60 日区间位置 + RSI + 均线）；AI 推荐/资讯/体检以表为过滤单位 |
| 个股诊股 | 输入代码一键聚合：行情概览 / 90 日 K 线大图 / 技术体检表 / 相关资讯与研报 / AI 综合点评（强免责）；推荐卡「🔍 诊股」直达 |
| 收盘报告 | 午间（12:15）/ 全天（16:15）自动收盘报告 + 盘中临时总结，历史按类型区分 |
| 风险分析 | 集中度/回撤/Beta/夏普/VaR + 压力测试 + 宏观四色信号（每项指标含通俗解读与操作建议） |
| 投资复盘 | 周/月/季复盘 + 行为偏差分析（追涨杀跌/过度交易等） |
| 虚拟账本 | AI 推荐回测统计 + 纸面交易练习 |
| 智能问答 | 结合实时行情、技术指标与持仓上下文问答（非持仓股票自动外部搜索识别），研报 AI 解读 |
| 系统设置 | 市场开关、通知与免打扰、投资风格、持仓数据来源、DeepSeek Key（用量统计与余额展示，余额≤¥5 弹窗提醒）、版本更新 |

## 技术栈

- 桌面壳：Electron + electron-builder + electron-updater（Windows NSIS 安装包）
- 前端：React + TypeScript + Vite + TailwindCSS
- 后端：Python FastAPI（PyInstaller onedir 内置）+ APScheduler
- 数据：SQLite（本地，%APPDATA%\ai-investment-analyst\data）；行情/资讯多源融合（腾讯 / 新浪 / 东方财富 / yfinance，缓存 + 熔断 + 自动重试）
- AI：DeepSeek API（未配置 Key 时自动降级内置规则引擎）
- 发布：本地构建 → GitHub Releases 直传（公开仓库，MIT 许可证）

## 快速开始（开发模式）

- 后端：`cd backend && .venv\Scripts\python run.py`（127.0.0.1:8756，数据与日志写入 backend 上级 data/）
- 前端：`cd frontend && npm install && npm run dev`（浏览器调试直接连本机后端）
- 桌面壳：`cd desktop && npm install && npm run start`（构建 TS 并启动 Electron）
- 打包安装包：`cd desktop && npm run dist`（输出到 desktop/release/，请先执行 backend 目录的 PyInstaller onedir 构建脚本并复制产物到 desktop/backend-bin/）

## 持仓数据对接（推荐用法）

1. 在「个人理财投资软件」中：设置 → AI 配置 → 导出文件夹，指向 `%APPDATA%\ai-investment-analyst\data\portfolio`（理财软件 v1.10.15+ 会在持仓变化时自动导出 portfolio_snapshot.json）
2. 本软件默认数据来源 = 快照文件：持仓总览页点「同步持仓」，此后每小时自动同步（含账户现金/总净值/交易记录/净值历史 180 天）
3. 不使用理财软件的用户，可在「系统设置 → 持仓数据来源」切换为**手动录入**，直接在持仓总览页维护持仓

> v1.0.5 起**不再直接读取理财软件 finance.db**：全部持仓数据经快照文件交换（纯本地文件，不触发杀毒误报，也避免对理财软件数据库的耦合）。

## 安全与误报说明

- 本软件需联网获取**公开免费行情/资讯数据**（腾讯/东财/新浪/yfinance）与调用 DeepSeek API，因此可能被部分杀毒软件/浏览器 SmartScreen 误报（未做代码签名）。这是开源个人项目的常见现象，请放心使用：
  - 下载后如遇 SmartScreen 提示：点击"更多信息" → "仍要运行"
  - 或右键安装包 → 属性 → 勾选"解除锁定" → 确定
- 本软件无任何数据收集行为，仅访问上述公开数据源与 DeepSeek 官方 API；所有数据（数据库/日志/AI Key 加密）存储在本机。
